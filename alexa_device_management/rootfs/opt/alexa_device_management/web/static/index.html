🔑 Amazon Anmeldung

Um Ihre Alexa-Geräte zu verwalten, müssen Sie sich einmalig mit Ihrem Amazon-Konto anmelden.

Voraussetzungen:

  1. In der Amazon Developer Console ein Security Profile anlegen.
  2. Client-ID und Client-Secret in den Add-on-Einstellungen eintragen.
  3. Die Redirect-URI (wird unten angezeigt) in den "Web Settings" des Security Profiles registrieren.
Diese URI muss unter "Allowed Return URLs" im Security Profile registriert werden.

Bitte zuerst Client-ID und Client-Secret in den Add-on-Einstellungen konfigurieren.
