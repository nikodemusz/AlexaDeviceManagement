🔑 Alexa-Web-Session verbinden

Für die private Alexa-Geräteliste wird eine Alexa-Web-Session benötigt. Der Assistent speichert Cookie und CSRF lokal im Add-on unter /data/alexa_web_session.json.

Ablauf:

  1. Der Browser öffnet direkt den lokalen Login-Start /auth/login.
  2. Der Server leitet auf den Alexa-App-Login-Proxy weiter.
  3. Amazon liefert nach erfolgreicher Anmeldung den Token an /ap/maplanding zurück.
  4. Die App speichert daraus die lokale Alexa-Web-Session und lädt danach die Geräteliste.
