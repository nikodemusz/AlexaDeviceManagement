# 2.8.1-rc1

- Fixed severe input latency in the HA → Alexa entity editor.
- Checkbox, name, description and category changes now update the affected card directly instead of rebuilding the complete device list.
- Added delegated editor event handling to avoid thousands of per-element updates during interaction.
- Increased autosave debounce to one second and batch changes into a single request.
- Moved serialization of large configurations out of the immediate input event path.
- Reduced unnecessary page-exit autosaves when no unsaved changes remain.
