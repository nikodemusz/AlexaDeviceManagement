# 2.8.2-rc1

- Fixed a lifecycle-status request storm triggered by every input and change event in the HA → Alexa editor.
- Lifecycle status refreshes are now deduplicated, skipped while the page is hidden and limited to explicit lifecycle changes, focus and a 60-second interval.
- Added CSS containment and `content-visibility` so off-screen device cards are not laid out and painted immediately.
- Reduced the impact of large entity inventories on the complete Home Assistant frontend while the configuration page is open.
