# 2.12.0-rc1

- **Feature**: Beim Ausrollen werden abgewählte Home-Assistant-Entitäten auch aus Alexa entfernt.
- **Bereinigung**: Nicht erreichbare Alexa-Duplikate derselben HA-Entität werden entfernt, sofern ein erreichbares Gegenstück vorhanden ist.
- **Fix**: Eine vollständig leere Alexa-Auswahl kann ausgerollt werden.
- **Fix**: Der Neustartknopf startet nur Home Assistant Core über `homeassistant.restart`, nicht Host oder Supervisor.
