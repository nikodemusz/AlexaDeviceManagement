# 2.8.3-rc1

- Fixed deployment of the HA → Alexa configuration after the performance changes.
- The deploy action now sends the current in-memory editor configuration directly to `/api/ha-export/deploy`.
- Deployment no longer depends on whether the delayed autosave has already completed.
- The obsolete empty-body deploy handler is intercepted to prevent stale or empty persisted configuration from being written.
- Deployment feedback now reports the written path, backup, selected entity count and Home Assistant validation result.
